# Evidence

구현 후 재현 가능한 검증 자료를 저장하는 곳이다. 예를 들면 정제된 테스트 결과,
장부 상태 예시, 훅 실행 추적, 모델 호출이 없었다는 증거, 재시작 영속성 결과,
제한된 검토 쿼리 결과가 해당한다.

토큰, 실제 사용자 ID, 비공개 메시지 본문, 원본 DB 덤프는 저장하지 않는다.
현재 구현 전 검증 자료는 다음 두 가지다.

- [2026-08-29 라이브 기준선 해시](2026-08-29-live-baseline.sha256): 라이브
  `1.0.0`의 두 소스 파일을 변경 없이 Git 기준선으로 가져왔는지 확인한다.
- [2026-08-29 원격 하위 디렉토리 설치 스모크](2026-08-29-remote-install-smoke.md):
  공개 Git 커밋을 고정해 임시 Hermes 프로필에 설치하고 기준선 해시를 확인했다.
