# Project instructions

이 디렉토리에서 작업할 때는 다음 규칙을 따른다.

1. 동작을 바꾸기 전에 `README.md`의 문서 지도를 따라 관련 권위 문서를 읽는다.
2. 같은 사실을 여러 문서에 복제하지 않는다. 링크로 연결한다.
3. 합의된 동작은 `SPEC.md`에 적고, 아직 정하지 않은 내용은 반드시 제안 또는
   보류로 표시한다.
4. `STATUS.md`에는 현재 확인된 사실만, `NEXT.md`에는 다음 실행 관문만 둔다.
5. ADR은 되돌리기 어렵거나 비용이 큰 선택에만 쓴다.
6. `~/.hermes`는 라이브 배포 대상이다. 문서 작업 요청만으로 라이브 파일 수정,
   게이트웨이 재시작, cron 등록, Discord 쓰기를 수행하지 않는다.
7. 자동화된 일반 사용자 계정(self-bot)을 사용하지 않으며, 기존 Hermes 권한
   검사를 우회하지 않는다.
8. 토큰, 실제 사용자 ID, 비공개 메시지 원문을 이 프로젝트에 저장하지 않는다.
9. 플러그인 코드와 테스트의 권위는 이 디렉토리에 둔다. 릴리스는 수정하지 않은
   공식 Hermes와 설치형 플러그인 하나로 구성한다. 부족한 범용 호스트 계약은
   upstream 기여로 분리하며, 개인 Hermes 포크나 동반 코어 패치를 배포물로 만들지
   않는다. 라이브 플러그인에서 개발본으로 역복사하지 않는다.
